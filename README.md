# 초록 취향 — 17문항 웹사이트

사진 선택 13문항과 생활환경 4문항으로 구성된 체험판입니다. 사진은 20가지 식물 후보를 보여줍니다. 결과는 임시 속성 규칙에 따른 취향 경향이며 검증된 성격검사나 최종 재배 적합성 판정이 아닙니다.

## 백업과 구글 드라이브
ZIP 파일을 그대로 구글 드라이브에 업로드하면 백업할 수 있습니다. 드라이브의 파일 공유 링크는 웹사이트 주소가 아닙니다. 드라이브 미리보기에서 이 앱이 실행되는 것은 아닙니다.

## PC에서 열기
ZIP을 압축 해제하고 index.html을 Chrome 또는 Edge로 여세요. index.html만 따로 옮기지 말고 app.js, data.js, style.css, assets 폴더와 함께 보관하세요. 기본 테스트는 브라우저에서 작동합니다. 로컬 파일의 이어하기 저장은 브라우저 설정에 따라 제한될 수 있고, 공유 기능은 기존 공개 사이트 주소를 사용합니다. 글꼴은 인터넷 연결이 없으면 기본 글꼴로 표시됩니다. 휴대폰에서는 웹사이트 주소로 사용하는 편이 편리합니다.

## 웹사이트로 운영하기
index.html이 있는 폴더 전체(또는 이 ZIP)를 정적 웹 호스팅에 업로드하세요. 압축의 최상위에 index.html이 있습니다. 서버 프로그램이나 설치 과정은 필요 없습니다.
Cloudflare Pages의 Direct Upload는 ZIP 또는 폴더의 드래그 앤 드롭 업로드를 지원합니다.
https://developers.cloudflare.com/pages/get-started/direct-upload/
구글 서비스를 원한다면 Google Drive가 아닌 Firebase Hosting을 검토하세요.
https://firebase.google.com/docs/hosting
서비스별 요금, 한도, 약관은 업로드 시점에 확인하세요. 어떤 서비스도 모든 상황에서 무제한·무중단을 보장하는 것으로 간주하면 안 됩니다.

## 파일 구성
index.html: 시작 화면과 웹페이지 기본 구조
style.css: 디자인과 모바일 화면
app.js: 응답 저장, 자동 이동, 분석, 공유
data.js: 질문, 식물 속성, 결과 유형
assets/: 식물 사진
credits.html: 사진 저작자, 출처, 라이선스

## 응답 데이터와 부하
응답과 결과 계산은 방문자의 브라우저에서 처리하며 운영자 서버에 전송하지 않습니다. 운영자는 방문자 응답을 모아 볼 수 없습니다. ZIP에는 방문자의 응답이 포함되지 않습니다. 웹 호스팅은 HTML, 스크립트, 사진을 전달하므로 접속자가 늘면 파일 전송량은 늘어납니다.
사진 선택과 환경 조건은 별도로 처리합니다. 환경 조건은 결과 안내에 반영되지만 후보별 안전성 및 적합성을 검증한 추천 DB는 아직 없습니다.

## 수정
사진, 문항, 속성은 data.js와 assets/에서 수정할 수 있습니다. 질문 구성을 바꿀 때는 데이터 version과 저장 키를 갱신해 이전 응답과 섞이지 않게 하세요. 사진을 재배포할 때는 credits.html과 라이선스 안내를 유지하세요.
